# Smart Note Agent 与 网页浏览器（Web viewer）配置

使用过程中两个常用配置的记录。

## 一、Smart Note Agent

在 Smart Note Agent 设置页按下表填写：

| 配置项 | 填写内容 |
| --- | --- |
| 项目 | （按需填写） |
| 提供商 | `deepseek` |
| API 密钥 | 你的 DeepSeek API Key |
| Base URL | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-v4-pro` |
| 请求超时 | `300`（慢的话改 `600`） |
| 首选语言 | 中文 或 自动 |

聊天面板顶部一般显示成两个按钮：**提问 ｜ 编辑**。
点 **编辑**，可以自由增加或删除笔记。

## 二、网页浏览器（Web viewer）

1. 打开 **设置 → Web viewer**，在「主页」输入：`https://gemini.google.com/app`
2. 关掉设置页。
3. 打开命令面板：`Ctrl + P`
4. 搜索：**打开网页浏览器** 或 **Web viewer**
5. 打开后应该会进入 Gemini。

# 隐藏复制粘贴的图片等附件

实现方式：**让图片集中存放 + 用 CSS 把附件从左侧文件栏隐藏**。

## 原理

Obsidian 的笔记本质是 Markdown 文本。图片不能真正塞进 `.md` 文件里，所以粘贴图片时，Obsidian 会自动把图片保存成一个图片文件，然后在笔记里插入类似：

```md
![[Pasted image xxx.png]]
```

左侧文件栏显示的是整个仓库里的文件，所以这些粘贴出来的图片也会显示出来。

解决思路有两步：

1. 把 Obsidian 的“新附件默认位置”设成 `附件` 文件夹。
2. 加一个 CSS 代码片段，在左侧文件栏隐藏图片文件和 `附件` 文件夹。

这样图片文件仍然存在，笔记里的图片也能正常显示，只是侧边栏不再显示这些附件。

## 操作路线

1. 打开 Obsidian 设置：

   `设置 → 文件与链接 → 新附件的默认位置`

2. 选择：

   `指定的文件夹`

3. 下面填写：

   ```text
   附件
   ```

4. 打开：

   `设置 → 外观 → CSS 代码片段`

5. 点文件夹图标，进入 snippets 文件夹，新建：

   ```text
   hide-attachments-in-explorer.css
   ```

6. 粘贴这段 CSS：

   ```css
   .nav-folder:has(> .nav-folder-title[data-path="附件"]),
   .nav-file:has(.nav-file-title[data-path$=".png"]),
   .nav-file:has(.nav-file-title[data-path$=".jpg"]),
   .nav-file:has(.nav-file-title[data-path$=".jpeg"]),
   .nav-file:has(.nav-file-title[data-path$=".gif"]),
   .nav-file:has(.nav-file-title[data-path$=".webp"]),
   .nav-file:has(.nav-file-title[data-path$=".svg"]) {
     display: none;
   }
   ```

7. 回到 Obsidian：

   `设置 → 外观 → CSS 代码片段`

8. 开启：

   `hide-attachments-in-explorer`

## 已有图片怎么处理

把左侧已经出现的 `Pasted image ...png` 拖进 `附件` 文件夹即可。

如果已经开启了“自动更新内部链接”，Obsidian 通常会自动把笔记里的链接从：

```md
![[Pasted image xxx.png]]
```

改成：

```md
![[附件/Pasted image xxx.png]]
```

## 如何恢复显示

如果以后想重新在侧边栏看到这些附件：

`设置 → 外观 → CSS 代码片段`

关闭：

`hide-attachments-in-explorer`

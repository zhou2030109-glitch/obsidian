# Margin Annotations

给 Obsidian 笔记添加靠近正文留白的旁注。

## 使用方式

1. 在编辑模式中选中一个词或一句话。
2. 右键选区，选择 `添加右侧旁注`、`添加左侧旁注`，或 `添加默认旁注`。
3. 在弹出的输入框里写旁注并保存。
4. 在输入框里选择标注颜色。
5. 旁注会显示在阅读模式和 Live Preview 编辑模式的左右留白处。
6. 右键旁注，可以 `编辑旁注`、修改颜色、移动左右位置，或 `删除旁注`。

## 媒体旁注

- 在旁注输入框里点击 `添加媒体` 可以插入图片、音频、视频或 PDF。
- 也可以直接把截图粘贴到旁注输入框里。
- 插入的媒体会保存到设置页里的附件目录，默认是 `Margin Annotations Attachments`。
- 旁注内容支持 Obsidian Markdown，例如 `![[image.png]]`、链接、列表和加粗。

## 设置

插件设置页可以调整：

- 阅读模式是否显示旁注
- 编辑模式是否显示旁注
- 默认旁注方向
- 默认标注颜色
- 旁注宽度
- 正文与旁注间距
- 旁注字号
- 媒体最大高度
- 媒体附件目录
- 是否自动迁移旧版行内旁注

## 0.9 升级点

- 新增每条旁注独立颜色。
- 新建旁注时可以选择颜色。
- 右键旁注可以修改颜色。
- 阅读模式和编辑模式中的高亮会跟随旁注颜色。
- 旁注边线会跟随当前标注颜色。

## 0.8 升级点

- 新增设置页。
- 新增媒体附件能力。
- 旁注输入框支持选择媒体文件。
- 旁注输入框支持粘贴截图。
- 编辑模式旁注现在可以渲染 Markdown 媒体内容。

## 存储方式

旁注正文保存在插件数据中，正文只保留高亮和隐藏定位锚点：

```markdown
==highlighted text==<span class="ma-anchor" data-ma-id="ma-example"></span>
```

删除旁注时，插件会同时删除这段定位锚点和插件数据。

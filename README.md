# Obsidian

这个仓库用于收集和开发 Obsidian 插件、扩展、CSS 片段和自动化工具。

## 插件

| 插件 | 说明 |
| --- | --- |
| [Pin Folder Top](plugins/pin-folder-top) | 把指定文件夹分支置顶到 Obsidian 文件列表顶部。 |

## 用户脚本（油猴）

| 脚本 | 说明 |
| --- | --- |
| [AI Chat → Obsidian](chatgpt-to-obsidian) | 在 ChatGPT / Gemini 网页端划词或单击工具栏按钮，一键把对话存进 Obsidian vault；可选 AI 润色排版（DeepSeek / OpenAI 兼容）；支持表格、公式、代码块。 |

## 目录约定

- `plugins/`：Obsidian 插件
- `chatgpt-to-obsidian/`：ChatGPT 网页剪藏油猴脚本
- `snippets/`：后续可放 CSS snippet
- `tools/`：后续可放开发辅助脚本
